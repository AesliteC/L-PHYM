Stage1 Method

Stage1 负责从长文本生成长时序人体动作。

最终路线采用 HumanML3D -> BVH -> MoConVQ native character retarget。 这条 BVH-native 路线让 HumanML3D 长序列更自然地进入 MoConVQ simulator observation 和 RVQ token space，为 segment-aligned GPT fine-tuning 提供更稳健的数据基础。

HumanML3D 到 MoConVQ 的端到端路线

长动作文本合成、BVH 导出、原生角色重定向、RVQ token cache、segment-prefix 微调和显式分段推理保持一致。

01

构造长文本和长 motion

从 HumanML3D clip captions 合成多段长序列，并保留原始片段边界。

02

导出 BVH 并走原生 retarget

使用 MoConVQ native MotionDataSet.add_bvh_with_character() 生成 simulator character observation。

03

建立 segment-aligned GPT cache

缓存 RVQ indices、latent_vq、T5 text feature 和 segment-prefix metadata。

04

显式分段推理和评估

推理传入 segments_json 与 segment_lengths，使训练时的 segment metadata 和推理协议保持一致。

Stage2 Humanoid Control

Stage2 将生成动作变成 H1 humanoid 可执行的物理控制。

Stage1 输出的是 long kinematic references。Stage2 需要处理平衡、接触、关节限制和 torque-compatible tracking：先把生成 BVH 转成 AMASS-like reference，再做 H1 retargeting，最后训练 teacher-student tracking policy，实现从参考轨迹到物理控制策略的转换。

Retargeting
BVH -> H1 构建 BVH-to-AMASS-like bridge，接入 HOVER/H1 retarget optimizer。
Conversion
72h -> 3.2h 通过 batched conversion 与 cache reuse，把 H1 转换流程加速约 22.5x。
Control
Teacher -> Student Teacher 使用 privileged reference state；Student 只保留可部署的 proprioception 和 masked commands。
Stability
Track Stage2 policy 展示了更稳定的 H1 跟踪执行，并补充 baseline 对比样例。
